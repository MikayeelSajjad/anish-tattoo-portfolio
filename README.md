# ANISH // INK — Defy The Norm

A modern, premium, dark-themed single-page portfolio website for high-end tattoo artist **Anish**, built with **Next.js 15**, **React 19**, and pure **Tailwind CSS**.

## ✦ Aesthetic & Theme
- **Theme**: Dark mode only (`#09090b` background), high contrast, edgy, cinematic, and cyber-gothic minimalist.
- **Accents**: Neon green (`text-emerald-500`) for glowing borders, buttons, radar indicators, and key highlights.
- **Visuals**: Ambient radial gradients, micro-mesh grid lines, and anti-gravity floating animations.

## ✦ Core Features
- **Minimalist Header**: Left brand mark `ANISH // INK` with live studio status; right glowing `BOOK SESSION` button linking to WhatsApp (+92 349 6907055).
- **Hero Section**: Bold headline *'DEFY THE NORM. INK BY ANISH.'*, subtext, CTAs (*'Secure Your Ink'*, *'View Portfolio'*), and anti-gravity floating card preview.
- **The Vault (Portfolio Section)**: Responsive gallery with category filter tabs (*Fine Line, Geometric, Surrealism, Dark Art*), grayscale-to-color hover effects, and interactive inspection modals.
- **Session Ritual (The Protocol)**: 4-stage transparent journey (*Concept Dialogue → Anatomical Mapping → Precision Session → Bio-Shield Healing*).
- **Interactive WhatsApp Session Builder**: Dynamic configurator letting clients select style, body placement, and scale to generate tailored WhatsApp inquiry briefs.
- **Islamabad Sanctuary**: Private atelier specs, hygiene protocols, and studio FAQ accordion.
- **Continuous Marquee Footer**: Pure Tailwind continuous infinite scrolling marquee:
  `NO TEMPLATES • CUSTOM ART ONLY • ANISH INK • ISLAMABAD`
- **Floating Quick-Action**: Pulsing floating WhatsApp trigger for mobile devices.

## ✦ Getting Started

### Prerequisites
- Node.js 18+ (Tested on Node 24)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/MikayeelSajjad/anish-tattoo-portfolio.git

# Enter project directory
cd anish-tattoo-portfolio

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

### Production Build

```bash
npm run build
npm run start
```
